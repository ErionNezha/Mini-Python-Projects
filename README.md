# 🧰 Mini Projekte Python

Koleksion me **23 mini-projekte Python** — secili me demo interaktive që ekzekutohet direkt në browser: kronometër, konvertues monedhash, enkriptim real AES-GCM, watermark imazhesh, text-to-speech, kërkim real DNS, ndarje file-esh në pjesë e shumë të tjera.

## 🚀 Si ta hapësh

Hap `index.html` në browser — tab-i **Live Demo** tregon hub-in me 23 mini-aplikacione. Zgjidh një projekt nga menuja dhe provoje.
